# Archived design and implementation plans

Historical documents kept for provenance. They describe how each phase was
designed and executed at the time and are **not** kept up to date; where they
disagree with the code or with `../ARCHITECTURE.md`, the code wins.

- `IMPLEMENTATION_CONTRACT.md`: the original handoff contract from the HTML
  design prototype to the Expo app (component signatures, tokens, screen specs).
- `2026-06-07-organizard-backend-design.md`: the sync/backend design (Worker, D1, mutation contract).
- `2026-06-07-backend-phase-1-scaffold.md`: execution plan for the Worker scaffold.
- `2026-06-08-edit-rooms-boxes-items*.md`: design + plan for editing rooms, boxes and items.
- `2026-06-08-multi-move-library*.md`: design + plan for the multi-move library.
- `2026-06-09-detail-gallery-print.md`: box detail gallery + printable labels.
